                                       🎬 Movies / TV Shows Streaming App  
----
✦ A Website application which allows users to view movies and TV shows through the use of “TMDB API” and to find the locations of their availability online.

🚀 Features
----
- 🔎 View trending movies & TV series
- 📡 Up-to-date with the latest movies and TV shows
- 🖼️ Display HD posters with movie details
- 🌍 Watch provider searching (Where to Stream Legally)
- ⚡ Sleek user interface with loading effects

🛠️ What Was Used
----
- HTML5
- CSS
- JavaScript
- TMDB API
- 📡 API Used

👀 By The Way...
----
The Movie Database (TMDB) API was used in this application, providing access to:
Movies & TV shows images (posters/backdrops) Watch provider information 
👉 https://developer.themoviedb.org/

⚙️ How It works
----
- Get data from TMDB API
- Automatically build a user interface with JavaScript
- Upon clicking, fetch more details and watch providers
- Displaying locations of availability (watch providers) if available
- Dealing with asynchronous data fetching

👋 Notes
----
Movie watch provider information does not exist in some cases Results returned may be null in some movies by TMDB (API’s normal behavior)
